01

Export tokens from Figma via Variables REST API

Use Figma's Variables API to export all design tokens (colors, spacing, typography, radius) as a structured JSON. Automate this with a script triggered on file publish.

# scripts/export-figma-tokens.sh curl -H "X-Figma-Token: $FIGMA_TOKEN" \ "https://api.figma.com/v1/files/$FILE_KEY/variables/local" \ | jq '.' > tokens/figma-raw.json # Then transform to Style Dictionary format node scripts/transform-tokens.js
Figma API Style Dictionary
02

Claude reads Figma JSON → generates React components

Pass the exported component specs and token JSON to Claude via the API. Claude generates typed React components, Storybook stories, and JSDoc comments in one shot.

◈ Claude prompt template

"Here is a Figma component spec (JSON) and our current design tokens. Generate a React component with TypeScript props, Tailwind/CSS-in-JS styling using the tokens, and a Storybook story file with Default, Hover, and Disabled variants."

Claude API React + Stories
03

Write generated files to your component library

A Node.js script writes Claude's output to the correct paths in your repo, then opens a PR with the generated components for team review before merging to Storybook.

// scripts/write-component.js const { component, story } = await callClaude(figmaSpec); fs.writeFileSync( `src/components/${name}/${name}.tsx`, component ); fs.writeFileSync( `src/components/${name}/${name}.stories.tsx`, story ); // Open PR automatically await octokit.pulls.create({ title: `feat: add ${name} from Figma`, head: `design-system/${name}` });

01

Detect code changes in the component library

A GitHub Action triggers on every merge to main. It diffs changed component files, extracts props, styles, and variant data from TypeScript source using ts-morph.

# .github/workflows/sync-to-figma.yml on: push: branches: [main] paths: ['src/components/**'] jobs: sync: runs-on: ubuntu-latest steps: - name: Extract component metadata run: node scripts/extract-metadata.js - name: Sync to Figma via Claude run: node scripts/sync-figma.js
GitHub Actions ts-morph
02

Claude diffs component changes → generates Figma update plan

Claude compares the previous and new component API. It produces a structured diff describing which Figma properties, variants, or tokens need to be updated, in a format the Figma Plugin API can consume.

◈ Claude prompt template

"Here is the previous version and new version of a React component. Identify all visual changes (new variants, prop renames, color token changes, spacing changes). Output a JSON action list for the Figma Plugin API to apply these changes to the matching Figma component."

Change detection Figma actions JSON
03

Apply updates via Figma Plugin API

A lightweight Figma plugin runs in the background, polls for pending updates from your sync endpoint, and applies them: renaming variants, updating token bindings, and syncing component descriptions.

// figma-plugin/code.ts const actions = await fetchPendingUpdates(); for (const action of actions) { if (action.type === 'UPDATE_VARIANT') { const node = figma.getNodeById(action.nodeId); node.name = action.newName; } if (action.type === 'UPDATE_TOKEN') { applyTokenBinding(action.nodeId, action.token); } } figma.notify(`✓ Synced ${actions.length} updates`);

■ Figma Setup

  • Enable Dev Mode on your file
  • Set up Variables for all tokens
  • Use component naming: ComponentName/Variant
  • Install the sync plugin from your team
  • Create a Figma Personal Access Token
  • Store FILE_KEY from your Figma URL

■ Storybook Setup

  • Use Storybook 7+ with CSF3 format
  • Install @storybook/addon-designs
  • Link stories to Figma frames via parameters
  • Enable Chromatic for visual regression
  • Set up storybook-addon-figma-plugin
  • Use autodocs for generated docs

■ Claude API Setup

  • Store ANTHROPIC_API_KEY in GitHub Secrets
  • Use claude-sonnet-4-20250514 model
  • Set max_tokens: 4096 for component gen
  • Add system prompt with your code style guide
  • Cache token JSON to reduce prompt size
  • Log all generated files for audit trail

■ Repo Structure

  • tokens/ — Style Dictionary source
  • scripts/ — sync + generation scripts
  • src/components/ — generated components
  • .github/workflows/ — automation
  • figma-plugin/ — Figma sync plugin
  • docs/ — generated component docs
